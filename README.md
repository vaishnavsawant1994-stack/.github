# Shared GitHub standards

This repository provides default community health files for repositories owned by **vaishnavsawant1994-stack**.

These standards improve contribution quality, security reporting, issue intake, and pull-request review without changing application code or implying that every project is production-ready.

Project-specific documentation, stage gates, qualification evidence, and repository-local policies remain authoritative whenever they are more specific than these defaults.

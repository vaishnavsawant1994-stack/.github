# Support

For setup help, questions, and non-security problems:

1. Read the repository README and existing documentation.
2. Search open and closed issues for the same problem.
3. Open a new issue using the most relevant template and include reproducible details.

Do not use public support issues for credentials, personal information, production data, or suspected vulnerabilities. Follow the security policy for sensitive reports.

Support availability varies by project maturity; no response-time guarantee or production service-level agreement is implied.
